# AI & Machine Learning – praktijk 5 vwo

In deze repository bouw je zelf de algoritmes uit de theorielessen, in p5.js.

| Project | Map | Praktijkles | Wat bouw je? |
|---|---|---|---|
| 1 | `1-regels-en-buren` | 1 en 2 | regels, k-nearest neighbours, perceptron, netwerk, confusion matrix |
| 2 | `2-cnn` | 3 en 4 | filters en pooling, en een eigen CNN dat cijfers herkent via je webcam |
| 3 | `3-taalmodel` | 5 en 6 | een taalbot op Wikipedia-artikelen (bijvoorbeeld over wielrennen), met autocomplete |

## Zo begin je

1. Klik op **Use this template** en maak je eigen repository.
2. Open de repository in VS Code (of in GitHub Codespaces).
3. Installeer de extensie **Live Server**.
4. Rechtsklik op `index.html` in de hoofdmap en kies **Open with Live Server**. Je ziet een overzicht van alle projecten.

Let op: als je `index.html` gewoon dubbelklikt, werken de projecten niet. De browser mag dan geen bestanden en geen webcam gebruiken.

## Zo werk je

- Open `sketch.js` van je project. Bovenaan staan blokken **STAP 1, STAP 2, ...** met uitleg in het commentaar.
- Werk de stappen op volgorde af. Onder de streep "Hieronder hoef je niets te veranderen" staat code die al klaar is.
- Commit na elke stap, bijvoorbeeld: `stap 2: k-NN werkt`.
- Beantwoord de vragen in `LOGBOEK.md`.
